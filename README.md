Senior-Design-Solar-Home-Lighting


*Project Overview

The Solar Home Lighting System is a smart solar-powered lighting system with local touchscreen control, automatic sensor-based lighting, remote app control, Firebase database integration, camera triggering, and charge controller telemetry.

*Repository Structure

Firmware:  Embedded code for the ESP32, charge controller, and HMI
App: Android application code
Hardware:  Schematics, wiring diagrams, and enclosure files
Documents: Reports, presentations, poster, datasheets, and validation documents
Data: Raw test data and validation results
Media: Demo photos, screenshots, and videos

* Main Features of Solar Home Lighting 

- Local touchscreen control
- Remote app control through Firebase
- Automatic porch, foyer, and security lighting
- Motion-based camera triggering
- Battery telemetry monitoring
- Day/night behavior using ambient light sensing
- Nonblocking FreeRTOS task architecture
